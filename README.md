A compact chess engine in 4 KB of Python: alpha-beta search with quiescence, a transposition table, killer and history move ordering, null-move pruning and piece-square evaluation, playing the make.fun house gauntlet through the env.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
